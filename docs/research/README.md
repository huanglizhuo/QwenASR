# Research Logs

These files collect the historical diaries and protocols from the autoresearch optimization loops.

## Index

| Document | Scope |
|---|---|
| [`experiments.md`](./experiments.md) | Single source of truth for all optimization experiment diaries, historical commit ledgers, and the future opportunity backlog. |
| [`README.md`](./README.md) | This index. |

## How to use these logs

- For **why a specific optimization exists**, search [`experiments.md`](./experiments.md) for the experiment name or parameter.
- For **why a parameter has its current value**, search [`experiments.md`](./experiments.md) for the parameter name.
- For **future optimization ideas**, see the **Opportunity Backlog** section at the end of [`experiments.md`](./experiments.md).

## Historical files removed

`ledger.md` and `programs.md` have been merged into [`experiments.md`](./experiments.md) so that all experiment, ledger, and backlog information lives in one place.
